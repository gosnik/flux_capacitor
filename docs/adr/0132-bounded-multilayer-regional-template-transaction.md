# ADR 0132: Bounded multilayer regional-template transaction

## Status

Accepted for v0.119.

## Context

Requiring zero sampled overflow before detailed routing prevented the regional physical-packing
stage from repairing precisely the bounded conflicts it represents. Alternate-layer templates
also fixed both vias at the original fragment endpoints, which withheld a decisive terminal and
multilayer escape variable.

## Decision

Require global reachability and accepted selected medial transitions before regional
materialization, but allow sampled, corridor, shared-physical, and clearance-shadow conflicts when
every observation maps into bounded regional windows. Clear those planning metrics only on the
private complete candidate passed to authoritative materialization.

Recursively split an oversized biconnected conflict block only at a deterministic conflict-free
spatial gap, retaining every edge. Merge windows touched by one differential pair or routing bus
before template search. Uncuttable oversized cores and incomplete coupled atoms fail explicitly.

Cache clearance-offset free-space and prepared NavMesh domains by net, layer, copper envelope, and
zone-fill policy. Enumerate a bounded template state containing an original-layer entry run-up,
entry via site, alternate layer and funnel corridor, exit via site, and exit run-up. Require
conservative clearance-offset free-space certificates for both run-up chords and every copper
layer touched by each via. Treat terminal
access tracks and via copper from every selected template as joint geometry during bundle search.
For a selected-global via portfolio, validate every attached same-layer run-up before retaining a
site. Carry the chosen site into the attached B-spline endpoint and later via relocation as one
state. An alternate-layer template remains fixed to the sites used to certify its NavMesh
centerline. Prune incompatible site identities for one shared via region during bounded partial
template construction rather than letting an access choice detach itself from route geometry.

Carry NavMesh endpoint-link guards into continuous optimization so a legal funnel endpoint that
lies outside the scan-cell interior is not falsely rejected. The selected B-spline remains the
routed geometry; its quantized tessellation, layer transitions, and run-ups are committed only by
one whole-board connectivity/DRC-clean transaction.

## Consequences

- Bounded sampled conflicts can be resolved by physical multilayer state rather than blocking the
  regional stage.
- Terminal escape, via location, layer selection, lane order, and continuous geometry participate
  in one deterministic bounded assignment.
- No partial via move, spline, or shove can escape exact transactional acceptance.
- Relocation is implemented only for selected regional via portfolios with checked attached
  run-ups. Arbitrary existing-via relocation and full geometry-general curved-run PNS remain later
  work.
